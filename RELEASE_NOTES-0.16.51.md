# 0.16.51 Chrome Web Store Review Candidate

This release contains the complete Chrome extension ZIP, including the ONNX Runtime / Transformers browser bundles that are omitted from the source repository.

Highlights:
- Local browser subtitles, YouTube CC track fallback, optional translation and transcript-to-AI workflows.
- Long-video HLS/DASH, BYTERANGE and MP4 audio seeking improvements, and bounded caching.
- Per-site caption auto-start memory and centered floating control.
- Chrome Web Store privacy-policy revisions, HTTPS-only remote translation API (except loopback), and removal of leftover adult-site references.

## Source vs installable release
GitHub Actions produces a **source-only artifact**. Download the attached `bili-subtitle-summary-0.16.51-cws-review.zip` for Chrome manual installation or Web Store submission.

This is a **review candidate**, not confirmation of Chrome Web Store approval or of real-site end-to-end regression testing.
