任意视频总结与直播实时字幕 · 本地识别
更新日期：2026年10月7日

本扩展用于从网页或本地视频/音频中获取或生成字幕、显示本地实时字幕、按用户选择进行字幕翻译，并在用户主动点击总结并选择目标服务后，将字幕和提示词提交到用户选择的 AI 网页用于总结。

一、本地处理的数据

扩展会在浏览器本地处理当前网页中的媒体信息、音频、字幕、转写结果、设置和运行状态。为发现可播放的媒体流，扩展可能观察当前标签页产生的媒体、播放清单或相关资源 URL；这些信息仅用于字幕提取、媒体定位和本地转写功能。

会话级媒体记录仅在浏览器本地短暂保存，并会随浏览器会话结束而清除。转写结果、设置和必要缓存可能保存在浏览器本地存储中，用于恢复字幕、避免重复识别和提升使用体验。

二、本地语音识别与模型下载

本扩展支持在用户设备上通过 WebGPU、WASM 或 ONNX 执行语音识别。相关语音识别模型可从 Hugging Face、HF Mirror、ModelScope 等模型托管服务下载并缓存在浏览器本地。

下载模型时，模型托管服务可能按照其自身政策获得普通网络请求信息，例如 IP 地址和 User-Agent；扩展不会把用户正在处理的音频、字幕或提示词上传给模型托管服务用于模型下载。

三、将字幕准备到第三方 AI 网页

当用户主动点击总结功能并选择 ChatGPT、Google AI Studio（Gemini）或 DeepSeek 时，扩展会生成或取得当前媒体字幕，打开用户选择的目标网页，将字幕 TXT 文件和总结提示词准备到该网页，并在确认附件已就绪后自动触发该网页的 Send / Run 操作。

点击“总结”并选择目标服务会启动自动提交。 这是一次由用户主动发起的操作；提交后，字幕和提示词会由所选第三方 AI 服务按其自身政策处理。

字幕 TXT 文件在被上传到第三方网页时，相关内容可能已经传输至该第三方服务。此后数据由对应服务依据其自身隐私政策和服务条款处理。

四、字幕翻译

扩展支持以下翻译方式：

  • 本地 OpenAI 兼容服务：字幕发送到用户自行配置的本地 Base URL（例如本机运行的 llama.cpp / LM Studio 等服务）。
  • 远程 OpenAI 兼容 API：仅在用户主动选择远程 API 并完成配置后，待翻译字幕文本才会发送到用户填写的 Base URL。

用户配置的 API Key 保存在浏览器本地；发起远程翻译请求时，仅作为鉴权信息发送给用户配置的对应服务。远程服务如何处理字幕文本和鉴权信息，由该服务自己的隐私政策决定。

五、网站媒体与字幕请求

为了完成用户请求的字幕提取或本地识别，扩展可能访问当前媒体页面使用的字幕接口、媒体文件、HLS/DASH 播放清单或媒体分片，并观察与媒体播放相关的网络资源地址。

对部分站点，扩展可能为自身发起的媒体请求临时设置必要的 Referer 等请求信息，以取得当前媒体资源。这些规则仅用于媒体处理功能，不用于广告、跨站追踪或用户画像。

六、本地存储与保留

  • 扩展设置、用户配置和必要的运行状态可保存在 Chrome 扩展本地存储中。
  • 语音识别或翻译模型可缓存到用户设备，以避免重复下载。
  • 媒体发现记录、转写任务和临时数据只为完成用户发起的功能而保留，并会按会话或扩展清理逻辑删除。

用户可通过扩展提供的清理功能、浏览器扩展数据管理功能或卸载扩展来移除相关本地数据。

七、反馈与诊断

当前发布版本未配置用于接收扩展诊断信息的在线反馈服务器。反馈页面可让用户在本地查看、复制或保存诊断信息；在未配置反馈服务器的情况下，这些信息不会发送给开发者。

如果未来启用在线反馈服务，本政策会在启用前更新，并在界面中明确说明会发送哪些数据。

八、第三方服务

用户主动使用相应功能时，可能涉及以下第三方服务：

  • ChatGPT / OpenAI
  • Google AI Studio / Gemini
  • DeepSeek
  • 用户自行配置的 OpenAI 兼容翻译 API
  • Hugging Face、HF Mirror、ModelScope（用于模型文件下载）
  • 当前媒体网站自身的字幕、音频或视频服务器

这些第三方服务独立处理其收到的数据，请同时查阅相应服务的隐私政策和使用条款。

九、开发者不会做的事情

开发者不运营用于收集用户视频、音频、字幕、提示词或浏览历史的服务器，不会出售用户数据，不会将浏览活动用于广告或用户画像，也不会将通过扩展权限获得的数据用于与本扩展公开功能无关的目的。

十、权限与有限使用

扩展申请的浏览器权限仅用于发现和访问用户正在处理的媒体资源、获取或生成字幕、保存用户设置、执行本地识别、按用户配置调用字幕翻译服务、维持用户发起的任务，以及把用户明确选择的内容提交到目标 AI 网页。

本扩展对通过浏览器权限获得的信息的使用遵守 Chrome Web Store 用户数据政策及其有限使用要求，数据处理限于本扩展公开说明的单一用途和用户可见功能。

十一、用户控制

用户可以决定是否启动字幕提取、本地识别、字幕翻译或 AI 总结流程，可以选择第三方服务、修改提示词和识别设置。AI 总结只有在用户主动点击总结并选择目标服务后才会启动；当前版本会在目标网页附件就绪后自动提交。

十二、政策更新与联系

当功能或数据处理方式发生变化时，本页面会同步更新。如有隐私或支持问题，请通过本项目的 GitHub Issues 联系开发者。
