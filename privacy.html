网页视频实时字幕与总结｜隐私政策

生效日期：2026 年 10 月 10 日
适用版本：0.16.51

本扩展用于在用户有权访问的网页视频及本地视频中发现媒体、提取可用字幕、进行浏览器本地语音识别、显示与翻译字幕，并在用户明确操作后准备视频总结。我们重视用户对音频、网页内容及浏览数据的控制。

1. 扩展处理哪些数据

  • 正在查看的网页与媒体信息：为了定位播放器及对应字幕/音轨，扩展在已获授权的网页和嵌入式播放器中读取视频标题、页面地址、播放进度、字幕轨信息，以及可能包含查询参数的媒体请求 URL、响应类型等必要元数据。它不会以构建浏览历史档案为目的处理这些信息。
  • 音频与字幕文本：当你启动字幕、启用明确配置的自动字幕，或点击提取/总结时，扩展可能读取网页中可访问的字幕轨、媒体音轨，或捕获当前标签页/播放器实际播放的声音。音频默认在你的浏览器中交由本地识别模型处理。
  • 你的设置与操作：包括语言、模型、翻译目标、字幕显示偏好、主动开启过字幕的网站、调试日志及主动配置的翻译接口地址和 API Key。
  • 本地文件：只有在你允许扩展访问文件网址并选择相关功能后，扩展才可能处理本地视频；不会主动扫描你的磁盘或其他文件。

2. 数据如何使用，什么情况下会离开设备

  1. 本地字幕和语音识别：识别计算默认在 Chrome 浏览器本地执行。下载模型权重时，浏览器会向 Hugging Face、HF Mirror 或 ModelScope 等模型托管服务请求模型文件；这些站点可能按照自己的隐私政策获知必要的网络连接信息（如 IP 地址），但此过程不会以识别服务请求的形式上传你正在播放的音频。
  2. 媒体获取：为从用户当前观看的内容获取字幕或音轨，扩展可能直接请求原视频站点或其媒体 CDN。媒体请求按网站自身的认证和网络规则处理；相关站点可能接收常规请求信息。扩展不提供绕过 DRM、登录或付费限制的功能。
  3. 可选远程字幕翻译：默认关闭。仅在你打开翻译功能、选择远程 API 并配置模型后，扩展才把需要翻译的字幕文本及必要的语言提示发送到你填写的 API 提供商。API Key 仅用于请求该地址的身份验证。远程接口必须使用 HTTPS；本机回环服务可使用 HTTP。本地服务或浏览器 ONNX 翻译则遵循相应的本地运行方式。
  4. 用户主动发起的视频总结：当你点击“提取并准备总结”并选择 ChatGPT、Google AI Studio（Gemini）或 DeepSeek，扩展会把整理后的字幕 TXT/视频标题交给所选网站的附件上传流程，并预填提示词；最终对话发送由你自行确认。附件上传动作本身会在点击该功能后发生，请在操作前确认是否愿意将这些内容交给该服务。
  5. 问题反馈：当前发行包未配置在线反馈收件地址，不会在后台自动向开发者上传诊断日志。你可以主动复制、导出日志或反馈报告并自行提供；其中可能包含页面地址、媒体 URL、报错信息等，请发送前检查并删除敏感内容。

我们没有在发行包中配置广告跟踪、出售用户数据或将录音与字幕发送到开发者的集中采集服务器的功能。扩展数据仅用于提供、维护和排查上述用户可见的字幕与总结功能，不用于个性化广告或信用评估。

3. 本地存储与保存时间

  • 扩展使用 Chrome 的本地/会话存储及浏览器缓存保存设置、模型权重、有限的媒体发现记录、字幕结果及临时任务。
  • 字幕结果缓存按程序设置的过期机制清理，目标有效期约 7 天；准备发送给 AI 网页的临时字幕任务有效期约 1 小时。异常退出或浏览器缓存管理可能影响实际清理时间。
  • 默认调试日志仅保存于当前浏览器会话，最多约 600 条；如果你主动启用“日志落盘”，会保存在本地存储中，最多约 4,000 条，直到清理或被新日志覆盖。
  • 站点开关记忆、翻译配置和 API Key 等设置保存在 Chrome 扩展本地存储中，直至你修改、清除扩展数据或卸载扩展。请不要在共享设备上保存敏感 API Key。
  • 识别模型等较大的资源可能继续保留在浏览器缓存中，用户可通过设置中的模型缓存清理功能或 Chrome 的扩展数据管理方式删除。

4. 接收数据的第三方

只有在相关功能运行时，数据可能发送到以下类别的服务：你访问的视频网站及其 CDN（媒体/字幕请求）；Hugging Face、HF Mirror、ModelScope 等模型文件提供方（模型下载）；由你主动选择和配置的远程翻译服务（待翻译字幕文本与授权信息）；以及你点击总结时选择的 ChatGPT、Google AI Studio/Gemini 或 DeepSeek（字幕附件和提示词）。这些服务各自适用其隐私条款。你也可能自行配置其他 OpenAI 兼容服务；请确认服务提供商及其数据使用条款后再启用。

5. 权限说明

为了在普通网页、包含 iframe 的播放器、B站和 YouTube 等网站实现字幕功能，扩展会请求广泛的网站访问权限。webRequest 用于识别媒体网络请求及响应类型；scripting 用于识别播放器和更新内容页面；tabCapture、offscreen 用于需要实时采集标签页声音的场景；declarativeNetRequest 仅为支持有特定请求头要求的媒体资源临时设置规则；storage、unlimitedStorage 与 alarms 用于本地数据、模型与任务管理；webNavigation 用于检测视频页面切换。file:// 功能需在 Chrome 中由用户额外允许。

上述权限不意味着扩展会向开发者发送你的完整浏览记录。网站权限可在 Chrome 的扩展管理页面中调整，但限制权限可能让相应站点的字幕功能不可用。

6. 你的控制权

你可以随时停止字幕与捕获；关闭自动字幕、站点记忆、字幕翻译及日志落盘；清理字幕缓存、日志或模型文件；更换或移除远程 API Key；也可以在 Chrome 中撤销网站访问权限或卸载扩展。涉及第三方服务的数据，如已上传至所选平台，需要按该平台的隐私控制方式管理和删除。

7. 安全与政策承诺

扩展使用浏览器提供的隔离环境及本地存储管理功能。远程翻译要求 HTTPS；浏览器本机回环 HTTP 服务除外。任何外部 AI 服务的安全性、保留期限和日志政策由对应服务提供商决定。我们承诺，对通过 Chrome API 获取的信息遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求），仅将数据用于向用户提供明确说明的功能及必要的运行维护，不出售用户数据，不用于个性化广告。

8. 更新与联系

当功能或数据处理方式发生实质变化时，我们会更新本政策及扩展内说明。隐私问题可通过此扩展在 Chrome Web Store 商品页面列出的开发者支持/联系渠道反馈。
